## Code Style & Formatting

### Style Property Ordering (React)
When writing styles (Inline styles, StyleSheet, or Styled Components), strictly follow this sequential order for properties:

1. **Size & Dimensions (Розмір та габарити)**
    - Examples: `width`, `height`, `minWidth`, `maxWidth`, `minHeight`, `maxHeight`, `flex`, `flexGrow`, `flexShrink`, `flexBasis`.

2. **Positioning & Layout (Положення та макет)**
    - Examples: `position`, `top`, `right`, `bottom`, `left`, `zIndex`, `display`, `flexDirection`, `justifyContent`, `alignItems`, `alignSelf`, `gap`, `margin`, `padding`.

3. **Appearance & Visuals (Вигляд та візуальні ефекти)**
    - Examples: `backgroundColor`, `borderWidth`, `borderColor`, `borderStyle`, `borderRadius`, `overflow`, `opacity`, `shadow...`, `elevation`.

4. **Typography (Типографіка - для текстових елементів)**
    - Examples: `fontSize`, `fontWeight`, `lineHeight`, `letterSpacing`, `color`, `textAlign`.

No need to comment or indent the group, just the order is enough
